# SweaterCo · XPY-NUS project 1

A curated English-language showcase of the **NUS DSS5105 Capstone Track 2 — SweaterCo Quick-Response Subcontracting Desk** team project.

The site presents the operating problem, system design, recorded interface, illustrative browser demo, and scoped evaluation results. It makes no individual contribution claims.

## Preview

Open `index.html` in a browser. No installation, API key, backend or build step is needed. All site asset paths are relative, including for GitHub Pages project URLs.

## GitHub Pages

Use a new personal repository, suggested name `sweaterco-portfolio`, under `Penny-hubweb`. Upload this folder's **contents** at the repository root. In **Settings → Pages**, choose **Deploy from a branch → main → /(root) → Save**. Read the actual URL and deployment status shown by GitHub; this package does not itself create or publish a repository.

## Scope

- The guided demo uses newly written preset examples. It does not call a model, run the Python allocator, or dispatch real orders.
- Saved first-test and error-informed retest results are explicitly separated. Repeated LLM runs are not independent messages.
- The allocator table reports selected official simulator results and their trade-offs. These are not observed business outcomes.
- The interface image is a recorded project capture predating later UI updates.
- No raw datasets, prompts, evaluation rows, logs, team discussion, credentials, source-repository history or backend code are bundled.
- The original team repository is neither modified nor made private by this package. Public Pages assets and this public repository can be downloaded.
